# 🌈riCast ForeCast

This is a simple WeatherForecast App, in which you can search for any location
and view the weather forecast of that location, and by defaut the app shows the
current weather data, for the user's current location.

I made this app as project to learn about APIs. While making this app i also
used jsDoc to document my code, as i wanted to try it out, in place of
typescript.

I also used my own css framework for this project.
[check that out here](https://github.com/israjatiangar/ricss)

## 📖 Things i Learned

I learned about working with external apis, and how to use them in your project.
I also learned the basics of JsDoc, which is very similar to typescript. While i
knew about basic DOM manipulation, this was still a good practise to improve my
skills in that area.

I'm still interested in learning on how to make my code more easier to
understand and maintain.

## ⚙️ Technologies used

- HTML
- CSS
- JavaScript
- JsDoc
- APIs:
  - OpenMeteoAPI(https://open-meteo.com/)
  - IPWhois API (https://ipwho.is/)

## ✅ Features i Implemented

- Uses geolocationapi and user input to suggeset the location
- Uses OpenMeteo Api to fetch data for the user location
- Uses ipwhos API to fetch user's current location if not found from user input
- Uses dialog to show Errors Messages.

## 🔗 APIs i used

- OpenMeteoAPI(https://open-meteo.com/)
- IPWhois API (https://ipwho.is/)
